**OpTask 1.0.0** for Windows 10/11 (x64) · Free for personal use

### What's new

- Initial public release
- Grouped, virtualised process list with live meters, end-task, process-tree kill, and priority control
- Admin shield on every elevated / system process that needs admin to end
- Performance tab — CPU, per-core, memory, GPU (any vendor), disk, and network graphs
- Insights — long-term CPU-time / peak-memory / disk-I/O rankings with expandable lists and rule-based advice
- System Health scan — roughly 30 checks with a health score, copy, and admin-gated Defender exclusions
- Full-screen Disk Scanner with drill-down, biggest-files, and right-click open / delete to Recycle Bin
- Idle Tasks — auto-close chosen apps when the PC goes idle, with a configurable timeout
- 5 themes + custom editor, close-to-tray, always-on-top, °F/°C, per-core CPU toggle
- Fully offline — no network, no telemetry

**OpTask 1.0.4** for Windows 10/11 (x64) · Free for personal use

### What's new

- Idle Tasks now also work while OpTask sits in the tray
- "Open file location" now works for apps in folders with spaces, like Program Files
- Deleting on a drive without a Recycle Bin (USB stick, network folder) now warns first that it's permanent
- "End process tree" can no longer end an unrelated program that reused an old process number
- After deleting in the disk scanner, the folders above it show their new size
